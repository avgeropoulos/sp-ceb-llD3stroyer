# Team Up: Godot Test

A separate, deliberately small Android graphics test using **Godot 4.5.1** and
its **Mobile** renderer. Sunset Garden contains animated Rocco, two guardians,
three collectible crystals, textured terrain, a stone terrace, foliage,
directional shadows, a following collision-aware camera and an FPS counter.
All models and materials are generated by the project; there are no paid assets.

## Play

Install `TeamUpGodotTest.apk` from the `godot-test-latest` release. Its package
ID is `com.roccoquest.teamup.godottest`, so it does not replace other games.
No editor, account, or computer is required to play the APK.

Move with the left thumb stick; drag open space on the right to orbit the camera.
Use JUMP and ATTACK (three hits per guardian). Collect all three crystals and
beat both guardians to finish. PAUSE stops play. The completion screen offers replay.
Keyboard: WASD, Space, F, Escape; right-mouse drag orbits. Controller: left stick,
A jumps, B attacks, right stick orbits. Touch buttons remain available with a controller.
The Android app pauses when it loses focus.

This is a visual/performance test, not a migration of the full Team Up game.
It has no save system or in-app updater. The displayed FPS measures this device's
actual frame rate; 60 FPS is a target, not a benchmark claim.

## GitHub builds

`.github/workflows/godot.yml` downloads a pinned editor and official Android export
templates, installs Android tools, imports scripts/assets, runs physics/gameplay
smoke tests, exports an ARM64 APK and verifies its signature. Builds reuse the
repository's existing game signing key and increment Android's version code.
Successful builds upload the APK and publish the dedicated prerelease.

Changes to `godot-test/` on `codex/team-up-open-world` trigger this workflow.
To use a different branch, update its branch filter. Existing Kotlin builds are unchanged.

## Local checks

```sh
godot --headless --path godot-test --editor --import
godot --headless --path godot-test --script res://tests/smoke.gd
```

Android export additionally needs the matching templates, SDK, JDK and signing
configuration provided by CI. Headless checks do not measure GPU performance;
judge visual quality and sustained frame rate on the phone.
